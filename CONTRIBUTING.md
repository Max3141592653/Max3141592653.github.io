# Contributing

Contributions are welcome.

## Getting started

1. Fork the repository and clone it.
2. Run `npm start` or any static server in the project root.
3. Make your changes in a feature branch.
4. Open a pull request with a clear description.

## Guidelines

- Keep code readable and accessible.
- Preserve the existing languages and add complete translations for new strings.
- Test in at least one Chromium-based browser and one Firefox-based browser.
- Follow the Code of Conduct.
